# DeltaESC Android Motor Detect v0.3.6 (0x0914)
Build-target specific overlay on the successfully compiled v0.3.5 source.
- E7 automatic resistor/inductance/flux VESC-method bench cycle
- E6 emergency stop
- F7/F8/F9 live values / status / fault
- Reuses frozen G30 NinebotCrypto pairing/transport without modifications
- Requires exact build `0x0914`. Old v0.9.13 app is incompatible.
- App retains separate explicit test confirmation and wheel-free warning.
The firmware is experimental and hardware calibration has not been measured.
